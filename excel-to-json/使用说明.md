# Excel 转 JSON 工具使用说明

## 用途

程序位于 tools/excel-to-json；表格和导出文件位于项目根目录的 excel。双击 excel/转表.bat 会同时转换 configs 和 language。

当前支持三类转表：

| 类型 | 输入 | 输出 |
| --- | --- | --- |
| 框架多语言表 | `excel/language/FrameworkI18n.xlsx` | `excel/export/framework/<lang>.json` |
| 游戏多语言表 | `excel/language/HoldemPokerI18n.xlsx` | `excel/export/game/<lang>.json` |
| 普通配置表 | `excel/configs/*.xlsx` | `excel/export/configs/<表名>.json` |

路径配置在（本工具根目录下）：

```text
configPaths.txt
```

配置文件中的相对路径均相对于 tools/excel-to-json；默认配置使用 ../../excel 指向项目根目录的表格目录，也可修改为其他位置。

## 输出之后

转换结果位于 `excel/export/`，分为 `framework`、`game` 和 `configs` 三个目录。后续同步由 `syncConfig` 单独处理，具体来源和目标以它的配置文件为准。

## 多语言表格式

多语言表默认读取 `Sheet1`。

第一行是表头，第一列应为 `key`，后续列为语言名，例如：

| key | zh-cn | en-us |
| --- | --- | --- |

每一行会按语言列分别导出到对应 JSON 文件：

```text
zh-cn.json
en-us.json
```

多语言表统一放在：

```text
excel/language
```

工具分别处理框架和游戏多语言表，导出到各自目录：

```text
excel/export/framework/<lang>.json
excel/export/game/<lang>.json
```

`FrameworkI18n.xlsx` 和 `HoldemPokerI18n.xlsx` 即使包含相同 Key，也不会互相覆盖，因为它们输出到不同目录。

## 普通配置表格式

普通配置表来源：

```text
excel/configs/*.xlsx
```

普通配置表放在：

```text
excel/configs
```

工具会批量处理该目录下所有 `.xlsx` 文件，并输出同名 `.json` 文件到：

```text
excel/export/configs
```

表头按“类型行”识别：`##var`（列名）/ `##type`（类型）/ `##`（描述）这类元信息行不会被当成数据行；
表格里有 `server` / `client` 字段归属行时，只导出 `key` 列和标了 `client`（或 `all` / `both`）的列。

模板中的 `Notes` 列只用于填写备注说明，不会被导出到 JSON。

## 运行环境

需要本机安装 Node.js 16 或更高版本：<https://nodejs.org/>

工具依赖（`node-xlsx` 等）通过 npm 安装，`node_modules` 不入库，所以**每台电脑第一次用都要装一次依赖**。
`excel/转表.bat` 会自动检测并安装，正常情况下不需要手动处理。

## 运行方式

双击运行：

```powershell
excel/转表.bat
```

首次运行会自动执行 `npm install` 安装依赖，需要联网，只需一次；之后每次运行都会直接转表。

`excel/转表.bat` 会调用tools/excel-to-json 目录中的转换程序。

```powershell
excel\转表.bat
```

也可以手动执行：

```powershell
cd tools/excel-to-json
npm.cmd install
node ./bin/index.js
```

## 常见问题

### Cannot find module 'node-xlsx'

说明这台电脑还没有安装工具依赖。原因是 `node_modules` 被 `.gitignore` 忽略，不会随代码库下发。

解决办法：直接运行 `excel/转表.bat`，它会自动安装依赖。
或者手动在 `tools/excel-to-json` 目录下执行：

```powershell
npm.cmd install
```

如果安装卡住或超时，一般是网络问题，可改用国内镜像源：

```powershell
npm.cmd install --registry=https://registry.npmmirror.com
```

### 依赖装到了错误的目录

依赖应该装在 `tools/excel-to-json/node_modules`。
如果在 `tools/` 或项目根目录下执行过 `npm install`，依赖会装到上一层，虽然 Node 逐级向上查找时仍能跑通，但换台电脑就会失效。
遇到这种情况，删掉上层多余的 `node_modules`，重新运行 `excel/转表.bat` 即可。

## 注意事项

1. Excel 文件需要关闭后再转表，避免文件被占用。
2. 框架、游戏多语言表或普通配置表的文件名、路径发生变化时，需要同步修改 `configPaths.txt`。
3. 转表会覆盖各自输出目录中的同名 JSON 文件，提交前应检查生成结果是否符合预期。
