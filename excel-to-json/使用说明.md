# Excel 转 JSON 工具使用说明

双击 `excel/转表.bat` 执行转换，首次运行会自动安装缺少的依赖，需要本机安装 Node.js 16 或更高版本。

## 多语言表

工具扫描 `excel/language` 目录中的所有 `.xlsx`、`.xls`、`.xlsm`、`.xlsb` 文件（不区分扩展名大小写），跳过 Excel/WPS 生成的 `~$` 临时锁文件，不递归扫描子目录。

每张表输出到 `excel/export/game/<Excel文件名（不含扩展名）>/`，语言列分别生成 JSON。例如：

```text
excel/language/HoldemPokerI18n.xlsx
  → excel/export/game/HoldemPokerI18n/zh-cn.json
  → excel/export/game/HoldemPokerI18n/en-us.json

excel/language/TexasDuelI18n.xlsx
  → excel/export/game/TexasDuelI18n/zh-cn.json
  → excel/export/game/TexasDuelI18n/en-us.json
```

新增语言表后直接再次执行转表，无需添加文件名配置。不同扩展名的表不能使用相同文件名，否则工具会报错，避免互相覆盖。

多语言表读取 `Sheet1`，第一行为表头，第一列为 `key`，后续列为语言名（例如 `zh-cn`、`en-us`）。表内重复 Key 会报错；某张表失败后仍会尝试其余表，最后报告失败。

转换会覆盖各表目录内的同名 JSON，并清理该目录中本次未产出的顶层文件。不会清理 `game` 根目录下旧版直接导出的 JSON，也不会删除已移除或改名表格对应的旧文件夹；这些旧产物请确认后手动整理。

## 普通配置表

`excel/configs/*.xlsx` 仍按原规则输出到 `excel/export/configs/<表名>.json`。

表头按类型行识别，支持 `##var`、`##type`、`##` 元信息行；有 `server` / `client` 字段归属行时，只导出 Key 列和标为 `client`、`all`、`both` 的列。`Notes` 列不导出，没有客户端字段的表不产出 JSON。

## 路径配置与手动执行

路径配置文件为 `tools/excel-to-json/configPaths.txt`，相对路径均以 `tools/excel-to-json` 为基准：

```text
gameI18nInputPath=../../excel/language
gameI18nOutputPath=../../excel/export/game
configInputPath=../../excel/configs
configOutputPath=../../excel/export/configs
```

也可手动在工具目录执行：

```powershell
npm.cmd install
node ./bin/index.js
```

转表只生成导出目录中的 JSON。工程内的语言同步脚本需要使用新的表名子目录作为来源。
