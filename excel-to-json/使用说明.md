# Excel 转 JSON 工具使用说明

## 用途

这个工具用于把项目内的 Excel 配置表转换成 JSON 文件。

当前支持三类转表：

| 类型 | 输入 | 输出 |
| --- | --- | --- |
| 游戏多语言表 | `excel/language/*.xlsx` | `assets/languages/<lang>/<lang>.json` |
| 框架多语言表 | `assets/framework/tools/i18n/FrameworkI18n.xlsx` | `assets/framework/language/json` |
| 普通配置表 | `excel/configs` | `assets/resources/configs` |

游戏多语言和普通配置表路径配置在：

```text
tools/excel-to-json/configPaths.txt
```

框架多语言路径由工具固定，不通过项目配置修改。

## 多语言表格式

多语言表默认读取 `Sheet1`。

第一行是表头，第一列应为 `key`，后续列为语言名，例如：

| key | zh-cn | en-us |
| --- | --- | --- |

每一行会按语言列分别导出到对应 JSON 文件：

```text
zh-cn.json
en-us.json
```

游戏多语言表统一放在：

```text
excel/language
```

工具会批量处理该目录下所有 `.xlsx` 文件，忽略 Excel 临时文件 `~$*.xlsx`，并合并导出到游戏资源目录：

```text
assets/languages/<lang>/<lang>.json
```

如果多个游戏多语言表中存在重复 key，工具会报错，避免静默覆盖。

框架多语言表固定放在：

```text
assets/framework/tools/i18n/FrameworkI18n.xlsx
```

并固定导出到框架资源目录：

```text
assets/framework/language/json
```

## 普通配置表格式

普通配置表模板：

```text
tools/excel-to-json/Temp.xlsx
```

普通配置表放在：

```text
excel/configs
```

工具会批量处理该目录下所有 `.xlsx` 文件，并输出同名 `.json` 文件到：

```text
assets/resources/configs
```

模板中的 `Note` 列只用于填写备注说明，不会被导出到 JSON。

## 运行方式

从项目根目录进入工具目录：

```powershell
cd tools/excel-to-json
```

如果依赖未安装，先执行：

```powershell
npm.cmd install
```

执行转表：

```powershell
node ./bin/index.js
```

也可以直接运行：

```powershell
export-excel-json.bat
```

`export-excel-json.bat` 会自动切换到工具目录，也可以从 `excel` 目录通过快捷方式或相对路径执行：

```powershell
..\tools\excel-to-json\export-excel-json.bat
```

## 注意事项

1. Excel 文件需要关闭后再转表，避免文件被占用。
2. 游戏多语言新增表时只需要放入 `excel/language`，不需要逐个配置。
3. 修改游戏多语言输出目录或普通配置表路径后，需要同步修改 `configPaths.txt`。
4. 框架多语言表属于框架资产，输入和输出路径固定，不在 `configPaths.txt` 中配置。
5. 框架多语言表只是导出到 `assets/framework/language/json`，是否在运行时加载取决于框架语言管理代码。
6. 转表会覆盖同名 JSON 文件，提交前应检查生成结果是否符合预期。
