# Excel 转 JSON 工具使用说明

## 用途

这个工具用于把项目内的 Excel 配置表转换成 JSON 文件。

当前支持三类转表：

| 类型 | 输入 | 输出 |
| --- | --- | --- |
| 游戏多语言表 | `excel/GameI18n.xlsx` | `assets/resources/language/json` |
| 框架多语言表 | `excel/FrameworkI18n.xlsx` | `assets/framework/language/json` |
| 普通配置表 | `excel/configs` | `assets/resources/configs` |

输入和输出路径统一配置在：

```text
tool/excel-to-json/configPaths.txt
```

## 多语言表格式

多语言表默认读取 `Sheet1`。

第一行是表头，第一列应为 `key`，后续列为语言名，例如：

| key | zh-cn | en-us |
| --- | --- | --- |

每一行会按语言列分别导出到对应 JSON 文件：

```text
zh-cn.json
en-us.json
```

`GameI18n.xlsx` 会导出到游戏资源目录：

```text
assets/resources/language/json
```

`FrameworkI18n.xlsx` 会导出到框架资源目录：

```text
assets/framework/language/json
```

## 普通配置表格式

普通配置表模板：

```text
tool/excel-to-json/Temp.xlsx
```

普通配置表放在：

```text
excel/configs
```

工具会批量处理该目录下所有 `.xlsx` 文件，并输出同名 `.json` 文件到：

```text
assets/resources/configs
```

模板中的 `Note` 列只用于填写备注说明，不会被导出到 JSON。

## 运行方式

从项目根目录进入工具目录：

```powershell
cd tool/excel-to-json
```

如果依赖未安装，先执行：

```powershell
npm.cmd install
```

执行转表：

```powershell
node ./bin/index.js
```

也可以直接运行：

```powershell
run.bat
```

## 注意事项

1. Excel 文件需要关闭后再转表，避免文件被占用。
2. 修改 Excel 文件名或输出目录后，需要同步修改 `configPaths.txt`。
3. 框架多语言表只是导出到 `assets/framework/language/json`，是否在运行时加载取决于框架语言管理代码。
4. 转表会覆盖同名 JSON 文件，提交前应检查生成结果是否符合预期。
